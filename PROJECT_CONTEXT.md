# Swasthya Sathii – Project Context

## Overview
Swasthya Sathii is a rural healthcare assistant web application built using React and Vite.

The goal is to help users:
- Check symptoms
- Understand severity
- Access nearby healthcare help
- Trigger emergency support

---

## Current Features

- Patient information form
- Symptom checker
- Severity prediction
- Confidence percentage
- Nearby healthcare help section
- Emergency call button (108)
- Dark mode / Light mode
- Responsive UI
- Footer with creator information

---

## Current Limitations

- Only 4 symptoms:
  - Fever
  - Cough
  - Headache
  - Stomach pain

- Rule-based logic
- No backend
- Static nearby help
- No doctor connectivity
- No location support
